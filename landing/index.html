Get an AI agent to do expert work you’ve never done.

I had no 3D background. AI coding agents built the 18 rooms in this playground in Blender, from my viewing videos and floor plans. The first attempts failed. A review loop made them usable, and you can run it on your own room.

How this started

I filmed the apartments I viewed and still couldn’t remember the layouts well enough to compare them. I had never modeled in 3D. I gave the videos to an AI coding agent, had it build each room in Blender, checked the renders against the footage and asked for fixes, round after round. The film shows it in 70 seconds.

What it taught me about working with AI agents

Each of these carries over to any field you don’t know yet.

  1. Expect the first attempt to fail.

    I recorded six fully automatic first attempts. They cost $17.51 in model calls, and none produced a usable room. Every room in the playground came out of review rounds after that. Plan your time and budget for the loop.

  2. Have it write down what it sees before it builds.

    The agent first lists the layout, doors, windows, light and materials it sees in reference frames, then turns those notes into a build recipe. When a room comes out wrong, you can tell whether it misread the video or built the notes wrong.

  3. Check against the source.

    An overview render looked right. Laying the wall lines over the floor plan showed a missing toilet wall and a sink and stove in the wrong order. Catching that took no Blender knowledge, only the source and a side-by-side comparison.

  4. Turn what worked into a skill.

    Once the loop worked, I packaged it as blender-room-tour for Claude Code and Codex. My next room starts from the method, and yours can too.

Try it on a room you’re in

blender-room-tour is the workflow I used, packaged as a skill for Claude Code and Codex. The agent does the Blender work. You check what it inferred against your video and ask for fixes. Plan on a few rounds. The geometry is estimated from the video, so treat sizes as approximate.

What you end up with

  • The blender-room-tour skill, ready to reuse on your next room.
  • An editable Blender scene, a .blend file you can open and change.
  • Review renders to compare against your video.
  • A local viewer for exploring the room on your computer.

How a build goes

  1. 1

    Film a room

    Walk slowly through any room with your phone. The agent can only model what the video shows.

  2. 2

    Your agent studies the video

    It pulls reference frames, writes down the layout, openings, light and materials, and turns those notes into a Blender Python recipe.

  3. 3

    It builds the room

    From the recipe it makes the editable Blender scene, the review renders and the local viewer.

  4. 4

    You check, then ask for fixes

    Read what it inferred and compare the renders with your video. Where something drifts, tell it what’s wrong. Some fixes take a few rounds.

Get started

You can do today

  • Film a slow phone video of a room you’re in.
  • Install Blender, FFmpeg and Python 3.11+, the tools the agent will run.
  • Explore the example rooms to see what you’re building toward.

Install the skill

Run this in your project to install the skill for Claude Code or Codex.

npx skills add jt-wang/move-room-playground --skill blender-room-tour

Technical details

Requirements

  • Claude Code or Codex
  • Node.js / npx
  • Python 3.11+
  • Blender
  • FFmpeg

Manual setup

  1. Download the skill and extract the whole blender-room-tour folder, keeping its scripts and assets together.
  2. Put it in your project. Claude Code: .claude/skills/blender-room-tour/. Codex: .agents/skills/blender-room-tour/.
  3. Ask your agent to read its SKILL.md and run doctor (doctor --stills for screened images only). It reports missing tools; it doesn’t install them.
